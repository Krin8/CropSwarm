# P44 consensus shortlist preregistration

Use the saved CropSwarm Kansas, Telangana and Makueni reference farms, all four unchanged presets and the saved three-year horizon for each farm. All work is offline. The original scorer, settings, priorities, displayed shortlist and earlier outputs are read-only. The result is an illustrative model sensitivity analysis that needs local validation.

## Variants and draws

- Kansas uses the original scoring engine and every P43 configuration with nitrogen and disease each on or off and water carryover off or at 43, 70 or 97 mm. These are 16 configurations including the original. Use the P43 code and evidence without adjusting the values or their scope. Give each named configuration equal weight, including the three water levels. They are a factorial design, rather than independent models or empirical probabilities.
- Telangana and Makueni have no P43 benchmark and each uses one copy of the original scoring specification. P42 was absent from the merged history at preregistration, so there is no smooth climate-fit variant in this study. Do not count inactive duplicate configurations.
- Regenerate the existing P22 joint draws with its saved input definitions, fixed seed 42, and all 512 draws per farm. Verify the original top-1 winner counts against P22, and the P43 Kansas rates on the same draws. Use the same P22 weather windows, farmer assumptions and constraints. Cross each Kansas draw with every P43 configuration. The fixed baseline and displayed shortlist are from the published nominal strategies.

## Ranking and consensus

- Compare canonical cycles under whole-year shifts, preserving within-year order. Every cell ranks all eligible canonical rotations, plus that draw's baseline as permitted by P22. Include the baseline once even if its cycle is also eligible. When its original hard flags are present, the row remains labeled as a baseline comparison. Rank by descending full-precision weighted score. Exact ties favor that draw's baseline, then the first canonical rotation in the scorer's catalog order. Report when there are fewer than three distinct candidates. There are no extra slots for ties.
- A cycle enters the consensus set when it places in the top three in **at least 50% of all variant-by-draw cells**. Repeat at **40% and 60%**. These thresholds are design choices. All cells stay in the denominator, so ineligible cycles receive no rank credit on that cell. Report top-1 and top-3 counts and shares for every cycle in the union of all eligible or admitted draw candidates, nominal eligible alternatives, and fixed reference strategies. All other canonical cycles have zero top-1 and top-3 counts by construction.
- For all thresholds, report consensus members and sizes, membership of the original P22 nominal winner, the share of original-only draw winners that belong to the consensus set, and overlap and differences from the four published alternatives. The fixed published baseline is excluded from the displayed-alternative overlap and reported separately, including top-1, top-3 and membership at each threshold. The assumed draw baseline can differ in Telangana and Makueni. Also report how often the current draw's baseline ranks first or in the top three.
- For every member at any threshold, test strict dominance in each cell where it is eligible or admitted as the draw baseline. Count a cell only if another feasible rotation scores higher on **all six normalized metrics** by more than the existing numerical tolerance of 1e-12. Equal metrics do not qualify. Keep the flagged baseline available as a target and require feasible witnesses. Report how many members ever meet this test, the number of dominated member–cell pairs and the number of admitted member–cell pairs. Empty sets and zero admitted pairs have unavailable dominance rates.
- Keep the published strategy shortlist as it is. Show the reference P18 evidence label for each reported rotation, including overlaps and missing shortlist items, and the P43 evidence labels and assumption grades where they apply. Label consensus results separately as counts within the tested scoring and assumption configurations. They provide no field evidence of rotation quality. Report every empty or threshold-sensitive set. No sampling intervals are assigned to the design frequencies.
