# P32 cross-state winter-wheat transfer preregistration

Freeze this plan before retrieving or extracting P32 data or running any evaluation. The question is whether unchanged P25/P27 weather-based yield models retain skill when transferred between Kansas, Nebraska and Oklahoma. County averages describe historical weather–yield associations. Crop rotation quality is outside the evaluation.

## Cohort and inputs

- The target states are Nebraska (US state ANSI 31) and Oklahoma (40), with Kansas (20) as the existing reference. Use winter-wheat county survey yields from the exact P20/P25 USDA NASS bulk snapshot if cached, otherwise retrieve that snapshot from the existing NASS source. Use 1990–2024 harvest years. Keep the same annual survey, Total domain, county and data-item filters. Prefer reported non-irrigated yields per county-year. Keep the published all-practice fallback flagged when needed. Reuse the P25 duplicate and value rules. No second crop, cohort or geography will be chosen after inspecting outcomes.
- Require at least 20 valid yield years and then at least 20 complete climate-and-yield years per county. Use the NASS archive's crop reporting district codes. Check that each county has one district. Use independently sourced public county centroid coordinates and preserve source, vintage and join evidence. Prefer the existing Census TIGERweb centroid convention and locally cached public boundary or centroid data. If a bundled public county polygon source is used, calculate centroids using an equal-area projection and log the method and source. Do not retrieve external geography under the network restriction. If suitable offline county geography is unavailable, report the blocked feature build rather than substitute cities or invented coordinates.
- Reuse the P25 feature implementation and catalog, with the Kansas winter-wheat window beginning October 1 of the preceding year and lasting 260 days. The model uses corrected rainfall, modeled water deficit with the same 550 mm crop demand and 60.2 mm initial-empty bucket capacity, heat days strictly above 30 °C, mean daily solar radiation and mean temperature. Supplied irrigation is zero for the weather deficit indicator. These catalog and proxy assumptions are unchanged. Use the same four daily POWER fields, AG/LST requests, 18-year chunks, four workers and the existing resumable bounded retry logic. Reject incomplete windows and record missing values, including -999.
- Kansas uses the committed P25 features and P27 county-to-district mapping. Its existing feature, scoring, evaluation and report artifacts will remain intact.

## Models, baselines and fixed evaluation

Reuse P25/P27 code and config for the county mean, county linear trend, ridge on training-only standardized features and a random forest. Learned models fit training-fold yield residuals and add back the training-derived trend. Unseen counties use the equal-county average of trends or means fitted on the applicable training set. Model grids stay fixed at ridge alpha 0.1, 1 and 10 and forest minimum leaf size 5 and 20 with 48 trees. Use seed 42, three-fold grouped inner selection by pooled RMSE, and the existing tie rule. Report all four methods and all five learned configurations.

1. **Target-state reference.** Run the P27 leave-one-USDA-district-out recipe independently within Nebraska and Oklahoma. Tuning groups are training districts of that state. The resulting held-out mean and trend estimates are the target state's own reference benchmarks for the transfer tests, using only other districts in the target state. Use the saved Kansas P27 pooled held-out-district baselines as Kansas's analogous own-state reference.
2. **Kansas transfer.** Fit on all eligible Kansas county-years only, tuning by Kansas USDA district with the same inner procedure. Use the unchanged unseen-county fallback for every Nebraska and Oklahoma county-year, including years shared with Kansas. A shared historical year can supply source-state labels only. No target yields enter a trend, scaler, hyperparameter choice or learner fit. Report the source-only mean and trend and compare on identical rows with the target-state held-out mean and trend. The target-state benchmarks can use observations from its other districts, which is a separate within-state reference procedure.
3. **Reverse and pooled.** Fit on Nebraska alone and Oklahoma alone, independently, then test each on every eligible Kansas county-year with the same protocol. For the pooled evaluation, leave out Nebraska, Oklahoma and Kansas in turn. Each pooled fold trains on the other two states. For three-fold inner selection, group by state-qualified USDA reporting district in those training states. This preserves the P27 tuning algorithm because two source states cannot supply three state groups. Report pooled and state-specific results. Match each state-specific result to its own-state held-out baselines.

Use P25/P27 RMSE (bu/acre), R² and Spearman with 1,000 fixed-seed paired 95% bootstrap intervals. Resample held-out USDA districts within each individual state and held-out states for the pooled estimate. Also report paired RMSE differences against each own-state baseline on identical rows. Whole-group intervals are descriptive. The pooled estimate has three spatial blocks. Compare methods only on rows they all evaluate. Preserve every planned test and report any unavailable cases and the reason. No retuning, feature changes or model selection on target data after evaluation. Report county and district counts, row counts, irrigation fallback mix and year range, fit and configuration counts, and both improvement and deterioration.

Network is limited to the existing NASS bulk data and cached, resumable NASA POWER requests. All results are illustrative and need local validation.
