# P47 chance-adjusted rank concentration preregistration

**EXPLORATORY.** This analysis follows the empty consensus sets in P44. Use the same cached inputs, canonical rotations, eligibility rules, baseline exception, scores, presets, variants and draws as the published P44 analysis. Kansas uses its 16 P44 configurations from P43, including the original. Telangana and Makueni each use the original. Use all 512 P22 joint draws per farm (P22 seed 42). No P42, P46 or P44b overlays enter this analysis. The scorer, published strategies and earlier results are read-only.

## Rank and threshold rules

- Within each variant-by-draw cell, rank admitted canonical rotations in descending full-precision weighted score. Break exact ties with the current draw baseline first, then canonical catalog order as in P44. Count a canonical cycle once. Check each preset's replayed top-one and top-three counts against the saved P44 per-rotation file before publishing.
- With rank (r) starting at 1 among (n) admitted rotations, define the percentile from the top as (100(r-1)/n), so the first rotation has percentile zero. At each threshold (q = 0.5, 1, 2), include rows with percentile strictly below (q). This takes the first (lceil qn/100ceil) rows and gives the best rotation a slot in a small cell. Report the slot-count range so the discreteness is visible. Percentile thresholds and rounding are design choices.
- A rotation is stable-top within the tested settings for a (q) if it is in that cell's top fraction for **at least half of all variant-by-draw cells**. Cells where a rotation is ineligible and exempt baseline status does not apply contribute zero hits. The denominator stays fixed across rotation labels. Use the canonical union from P44, including nominal and published reference rows with zero hits where applicable.
- Report all farms, presets and thresholds, including empty sets. Give each member's canonical cycle, hit count and share, the largest observed share even for an empty set, and membership and shares for the fixed published baseline and each displayed alternative. Use the fixed strategy identities from P44.

## Chance comparison

- In each of **1,000** independent null replicates, shuffle rank labels uniformly within each cell's actual set of admitted rotations. Preserve the canonical search universe, each cell's eligibility mask, number of cells and slot count for each threshold. A uniform ordered sample without replacement of the first (lceil 0.02nceil) labels implements the required shuffle. The smaller top fractions use prefixes of that same sample. Use a fixed seed of **4747** and reproducible child streams per farm. Null shuffles are independent across cells. Use the same null distribution for all presets because eligibility and top slot counts are the same.
- For each threshold report the null mean stable-top set size, the null mean largest share, and the central 95% empirical range of the null largest shares. Report plus-one empirical upper-tail p-values ((1 + 	ext{exceedances})/(1000 + 1)) for the largest share, the set size, and both jointly, with equality counted as an exceedance. The largest share is maximized across all rotation labels in both the observed and shuffled study. The null seed, replication count and summary choices are design choices. Report unadjusted descriptive comparisons across all farm, preset and threshold combinations.
- This null preserves eligibility but removes repeated score structure across closely related assumptions and variants. A small tail probability is evidence of rank concentration relative to independent shuffled rankings. Stability across our own variants provides no evidence of real-world rotation quality. Percentiles and shares describe an illustrative model that needs local validation.
