## Variables and scoring grid

- Use the scoring engine's Kansas cool-season winter-wheat window, starting October 1 and lasting 260 days into the harvest year. Compare seasonal post-bucket water deficit (millimetres unmet, rainfed) and the number of days whose daily maximum strictly exceeds the crop catalog's 30 °C heat threshold. Check the windows in each state's saved feature rows against the scoring window. Use the frozen crop catalog, Kansas storage, irrigation and scoring policy.
- The water-deficit grid is 0 to 500 mm in steps of 25 mm. The heat grid is 0 to 60 days in steps of five days plus 26 and 27 days, the two integer counts on either side of the scoring screen. These design choices are fixed before evaluation and include potentially extrapolated values. For each state and feature show the observed marginal range and mark all grid values outside it. Marginal support alone cannot establish plausible joint weather conditions.
- Sweep one variable at a time. Hold the other weather features at the medians of the cached Kansas county-year feature table. Use the same Kansas scoring reference in all three state comparisons. On the scoring side, provide the median seasonal rainfall and mean temperature to the unchanged historical metrics function through a synthetic daily window with mean temperature and rainfall distributed uniformly. Set exactly the requested count of days strictly above the heat threshold, with remaining days at the threshold. This supplies the inputs to the existing climate-fit screen. Its single synthetic window gives a pass or fail, which is the scoring engine's 0–1 historical share for one window.
- Intervene on water deficit **after** the daily bucket, setting unmet millimetres and the corresponding unmet-demand fraction before passing the resulting one-slot additions to the unchanged rotation scorer. Water deficit is an output of the bucket, so this intervention isolates its role in the sub-scores while rainfall remains fixed. It does not describe a physically realizable rainfall sequence at every grid level. Use the same setup for the heat sweep, holding deficit at its Kansas median. Report only the water-use and climate-fit sub-scores, where a larger number is more favorable. These are component responses, separate from hard feasibility checks and strategy rankings.

## Held-out partial dependence and comparison

- For each feature, replace that column with each grid value for every row of each held-out district. Keep the remaining columns at each held-out row's observed values, following the P27 partial-dependence recipe. Evaluate the fold's yield-residual learner and average first within each district, then across districts weighted by held-out row count. Show changes relative to the first grid point in bu/acre. The fixed Kansas median profile is for the scoring engine only. The partial dependence averages across each state's observed backgrounds, and replacing correlated features can create uncommon combinations. A district bootstrap with 1,000 draws, seed 42, and the existing 2.5th and 97.5th percentiles resamples intact fold curves. These intervals summarize district variation without refitting.
- Compare both scoring sub-scores with both learners for both variables in all three states. Compute Spearman rank correlation on the full grid, using average ranks for ties, plus the same comparison on grid points in the state's observed marginal range. The result is unavailable when either curve is constant or fewer than two usable points remain. Apply an absolute numerical tolerance of 1e-9 in each curve's own units to classify adjacent changes and numerical ties. Describe each curve as flat, non-increasing, non-decreasing or non-monotone. Compare adjacent grid increments by sign. Report the spans where both move in the same direction, move in opposite directions, or exactly one is flat. Merge contiguous intervals only when the sign pair and marginal support status stay the same. Mark an interval as supported only when both endpoints fall within the observed state range. Use the percentile district bootstrap for Spearman when estimable and record how many draws produce an estimate.
- The ledger direction concerns the two linked comparisons, water-use versus deficit and climate-fit versus heat. Call it supports only if both pairs in every state and learner have same-direction movement and no opposite-direction movement on supported grid steps. Call it does not support if there is opposite-direction movement and no same-direction movement in any linked comparison on supported steps. Otherwise call it mixed. Report flat segments and unavailable correlations regardless of direction.

The values and grid are illustrative and need local validation. This checks whether the scoring assumptions resemble associations in county-average yields. The comparison cannot establish causal crop response, field yield or the value of a rotation recommendation.
