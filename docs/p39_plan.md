# P39 weather–yield associations by state preregistration

Use only the committed P25 Kansas feature table and P27 district mapping, the P32 Nebraska and Oklahoma feature tables, and the frozen P25 configuration. Use all cached eligible winter-wheat county-years in each state, including series explicitly reported as non-irrigated and the flagged all-practice fallback. Preserve the datasets, county-to-district assignments and eligibility rules. No fetches, feature selection, crop changes or edits to earlier results. Analysis settings below are design choices. Results are illustrative and need local validation.

## State-specific coefficients

- Fit the P25/P27 ridge to residual yields after fitting the existing county linear trends. Use the five unchanged weather features from the fixed winter-wheat window: season rainfall, modeled water deficit, heat-day count, mean daily solar radiation and mean temperature. Standardize predictors with the fitting rows' mean and population standard deviation. Do not standardize residual yields. Ridge has an unpenalized intercept and uses squared-error loss with an L2 penalty.
- Fit Kansas, Nebraska and Oklahoma separately. Select alpha from the frozen P25 sequence (0.1, 1, 10) using three-fold grouped inner CV on USDA reporting districts, minimizing combined held-out squared error, equivalent to pooled RMSE. Refit detrending and scaling inside each fold. First-listed alpha wins exact ties. After selection, refit on all eligible county-years of that state.
- Use 1,000 whole-district resamples with replacement per state, seed 42, and keep all county-years within each sampled district. Refit county trends, scaler and ridge on each resample at that state's selected alpha. The percentile 95% intervals condition on that alpha. Use independent resamples across states. Report all 15 standardized coefficients in bu/acre per within-state predictor standard deviation. For each feature report whether all three marginal intervals share a common value, which state pairs' intervals overlap, and whether their point signs differ. Report all 15 pairwise coefficient differences (Nebraska minus Kansas, Oklahoma minus Kansas, Oklahoma minus Nebraska) with percentile 95% intervals and whether each excludes zero. A sign flip in the point estimates and an interval excluding zero are separate observations. These descriptive intervals are unadjusted for multiple comparisons, and the district counts are small.

## Pooled held-out comparison

- Compare two pooled ridges on the same county-years. Both predict county-trend residuals and include the same five pooled-standardized weather columns and three state indicators. The second adds each of the five standardized weather columns multiplied by each state indicator (15 interactions). Apply the same ridge penalty to all slope and indicator columns and leave the intercept unpenalized. Keep all three state indicators and all three sets of interactions so the penalty treats states symmetrically. Indicators stay at 0 or 1. Fit the weather scaler on the fitting rows before multiplying by the indicators.
- Hold out one whole state-qualified USDA reporting district at a time. The held-out test rows match the corresponding in-state P27/P32 district fold; the pooled training rows add the other two states. Use the same P27 county-trend recipe within each state, including its equal-training-county trend fallback for an unseen county. Fit those trends on fitting rows only. The same calendar year can occur in training and holdout in this spatial evaluation.
- Tune the two ridge variants independently in each outer fold using three-fold CV grouped by state-qualified training district. Use the same alpha sequence, pooled validation loss and tie rule as in the state fits. Refit trends and scaler within every inner split. Refit the selected ridge on the outer training set. Count each evaluated alpha, the inner fits, final fits and coefficient bootstrap refits.
- Report RMSE (bu/acre) for both models, by state, by district fold and pooled over all held-out rows. Report the paired difference (interactions minus common slopes) with the P25 1,000 fixed-seed percentile 95% district bootstrap. Draw whole districts with replacement within each state and keep that state's district count fixed in the pooled bootstrap. A negative point difference favors interactions; describe a clear held-out improvement only if the pooled interval is entirely below zero. Report all folds, including any increased error.

The coefficients describe conditional associations in county-average yields. Differences can reflect management, varieties, irrigation, variation in feature scales, or correlated weather predictors. These comparisons cannot establish weather physiology or rotation quality.
