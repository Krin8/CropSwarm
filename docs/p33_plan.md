# P33 yield prediction intervals preregistration

Commit this design before evaluating any coverage or interval width. P33 uses cached P25/P27/P32/P37 inputs. All previously saved data, models, settings, scores and predictions remain as published. P33 fits separate split-conformal copies of the existing ridge and random-forest recipes because the published point models used all outer training rows, including the rows needed here for independent calibration.

## Kansas folds and interval construction

- Use the existing P25 pooled preferred-with-all-practice-fallback Kansas winter-wheat cohort and P27 USDA reporting districts. Evaluate both P27 leave-one-district-out and P25/P27 leave-one-harvest-year-out. Sort county-years by FIPS and year before splitting.
- For each outer split, take the first deterministic three-way GroupKFold split within outer training. Its validation groups supply the conformal calibration rows. Group by USDA district for district holdout and by harvest year for year holdout. The other groups form the proper-training set. Within that proper-training set, apply the unchanged P25/P27 grouped inner search with the same group variable, detrending, ridge scaling, grid, selection rule and seed. Fit on the proper-training set only. Predict calibration and test rows with the same frozen fit, using the original equal-training-county trend fallback for new counties. Do not refit after calibration.
- For each model, calculate absolute calibration errors in bu/acre. At nominal level p = 0.80 or 0.90, use the ceil((n+1)p)-th smallest of n calibration scores. If that rank exceeds n, the interval is unbounded and is reported as such. Use symmetric intervals around predictions, with inclusive endpoints and no clipping. Treat county-years as calibration scores and report calibration counts. Spatial and temporal dependence, and distribution shift, can violate the exchangeability conditions for nominal coverage.
- Report coverage and mean full interval width in bu/acre for both learners and levels, pooled and in every outer fold. Compare mean full width to RMSE of the county-mean point baseline on the same rows. In Kansas that baseline uses the same proper-training county means or fallback. Report the ratio with the RMSE, without treating it as a calibration criterion.
- For coverage intervals, reuse P25/P27 seed 42, 1,000 paired whole-block draws and the 2.5th and 97.5th percentiles. Resample outer districts or outer years for the pooled result. Within a held-out district resample years, and within a held-out year resample districts. Use the same sampled groups for both learners and levels. A one-block subset has no coverage interval. Report district and year diagnostics for both schemes, flag empirical coverage below nominal, and mark the lowest and highest deciles of Kansas annual means as descriptive yield extremes. Use the lowest and highest ceil(0.10 times the number of harvest years) annual row means, with chronological ties. This is an evaluation slice only and will not guide any fit or radius selection.

## Transfer and local interval recalibration

- First evaluate Kansas-only fitting and calibration on every cached P32 eligible Nebraska and Oklahoma county-year. Use the Kansas pooled cohort and the deterministic district calibration split above, with the same proper-training tuning. No target labels enter that fit or its Kansas radii. This measures spatial transfer across shared historical years. Use the saved P32 own-state district-held-out county-mean RMSE on matching rows for the width comparison.
- Separately use the P37 reported non-irrigated cohort and exact common test rows. For each target district, use the P37 first 0, 3, 5, 8 or 12 observed years and common test tail from its thirteenth observed year. Keep the P37 district exclusions. For each distinct common-test origin, restrict Kansas non-irrigated records to earlier years, then use the fixed Kansas district proper-training/calibration split and same learner settings. Use these same frozen model centers for every local history size. At k = 0 use the Kansas radius. At k = 3, 5, 8 and 12 use only absolute residuals from that district's first k observed years to recompute its radius. This recalibrates interval width only. It uses P37 chronology and cohort and does not reuse P37's fitted local point predictors. No target test years or other target districts calibrate a radius.
- Report both nominal levels and both learners for each state and k on the identical later rows. Use the same district-block coverage bootstrap within each state and setting. Report width relative to the saved P37 county-mean RMSE for k > 0. At k = 0 the local county mean is unavailable. For this chronological comparison, report pooled state results and district breakdowns; show counts and every shortfall.

Every interval evaluation is counted once by protocol, county-year, learner, nominal level and k where applicable. Fold and diagnostic views summarize those same intervals. Use cached inputs only. Do not change rotation scores or use this analysis to validate rotation recommendations.
